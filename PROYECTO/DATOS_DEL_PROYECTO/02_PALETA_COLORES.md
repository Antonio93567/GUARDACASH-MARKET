# Paleta de Colores — GUARDACASH MARKET

Paleta **neón / fintech** aplicada en la app. La referencia original está en `..\..\paleta de colores\` (NO modificar).

| Nombre | Hex | Uso |
|---|---|---|
| Cian | `#00FFFF` | Acentos neón, botones primarios, resaltados |
| Cobalto | `#1E40AF` | Fondo/tonos oscuros azulados, énfasis |
| Verde | `#33CD31` | Ganancias, positivos, éxito |
| Magenta | `#B6018B` | Acentos secundarios, detalles |
| Negro | `#000000` | Fondo principal |
| Gris | `#E0E6ED` | Textos secundarios, bordes |

## Implementación en código

- `..\GuardacashMarket\Resources\Styles\Colors.xaml` — definición de colores.
- `..\GuardacashMarket\Resources\Styles\Styles.xaml` — estilos (BtnPrimary, BtnSell, BtnOutline, BtnCobalt, CardStyle, CardNeon, NeonEntry…).
- `..\GuardacashMarket\Platforms\Android\Resources\values\colors.xml` — colores nativos Android (cian/negro/gris/cobalto).
