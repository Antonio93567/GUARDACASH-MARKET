# GUARDACASH-MARKET
GUARDACASH MARKET es una app híbrida (.NET MAUI) que convierte el hobby de jóvenes en negocio: gestiona servicios, cotizaciones, pedidos, ganancias y reinversión, Android y Windows. Esta app se encuentra en etapa de desarrollo. Vinculada al desafío "Del hobby al negocio" de NexoMarket (United Solutions Network, UNI CUR Estelí).
